### Como funciona um IF

Condicional IF é uma estrutura de controle, é utilizado para criarmos verificações e decisões no código.

as linhas de código do if só serão executadas caso a condição for verdadeira (true), caso contrário (false), entrará no else da condição.

// A estrutura é basicamente essa:
se (tal coisa for verdade) {
Faça isso
} senão {
Faça isso
}

No exemplo de código estou verificando a idade passada na variável.

Podemos criar várias linhas dentro do if, inclusive colocar um if dentro do outro (if aninhado).

### Lista de condicionais

x < y (maior que)
x > y (menor que)

x == y (igual à)
x !=y (diferente de)

x >= y (maior ou igual)
x <= y (menor ou igual)
