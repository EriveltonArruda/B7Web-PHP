Um loop é basicamente um comando que vai executar o mesmo código diversas vezes dependendo da condição.

O Loop While é um comando útil, porém perigoso, mas porque perigoso? porque dependendo da condição, ele pode ficar em um loop infinito porque o loop será executado ENQUANTO a condição for verdadeira.

### Iteração (Adição) de números

// Adicionar um número à uma variável no loop
$numero = $numero + 1; // a variável receberá o valor atual + 1;
$numero += 1; // pega o valor que já tem e adiciona mais 1;
$numero++; // Adiciona mais um;
