Array é um tipo de variável que consegue armazenar vários valores dentro dela.

### Criando um array.

Para determinar um array, abrimos colchetes e colocamos os valores dentro dele separados por vírgula.

### Pegando itens do array.

Para pegar o primeiro item do array também utilizamos colchetes [], só que dentro dele colocamos a sua posição.

Arrays começam do 0, então o primeiro item é a posição 0, o segundo é a posição 1 e assim sucessivamente.

### Armazenamento

Arrays aceitam todos os tipos de dados (string, números, boolean)
